# O3 三行九格截图说明

本目录保存 Prometheus 看板的截图。阅读图片时，请注意以下三点。

## 1. 图片中的时间是 UTC，北京时间需要加 8 小时

例如，图片上的 `2026-10-28 02:20:00`，对应北京时间 `2026-10-28 10:20:00`。

对照服务器实验记录时，请先统一时区，避免把不同时间段的数据放在一起比较。

## 2. 资源图中间的缺口是监控数据缺失，不代表资源数值为零

UTC 约 `02:31～02:37`（北京时间约 `10:31～10:37`）期间，node_exporter 曾停止运行，Prometheus 无法正常采集服务器资源指标。恢复 node_exporter 后，数据继续采集。

因此，CPU、可用内存、磁盘和网络等资源图在这段时间可能出现空白。部分 Stacked（堆叠）图会把缺失段画到图底，但不能据此认为这些指标真的降到了零，也不能据此判断服务器当时没有负载。

## 3. 第一行使用适配 enrolld 示例程序的业务指标

本实验使用的示例程序没有提供真实的“全体学生完成率”和“在线人数”，所以第一行采用以下三个指标：

| 格子 | 实际展示的指标 |
|---|---|
| 第一格 | 查看课程的读请求中，成功且耗时不超过 50 毫秒的比例，目标为 99% |
| 第二格 | 提交选课请求的成功率 |
| 第三格 | 最近 10 分钟内确认的选课记录数 |

第三格统计的是记录条数，不是在线人数，也不是去重后的学生人数。它使用最近 10 分钟的滚动窗口，因此数值可以下降，不是从实验开始累计至今的总记录数。
